Politique de confidentialité

Politique de confidentialité du guide de Ksar Sghir : données du navigateur, services externes, statistiques et publicité.

Dans cet article

  1. 1. Données collectées
  2. 2. Ce qui est enregistré dans votre navigateur
  3. 3. Services externes
  4. 4. Statistiques et publicité
  5. 5. Messages
  6. 6. Contact

1. Données collectées

Aucune donnée personnelle n’est demandée pour naviguer sur le site ; il n’y a ni inscription ni compte.

2. Ce qui est enregistré dans votre navigateur

Le site enregistre uniquement dans votre navigateur votre choix de thème clair ou sombre et, le cas échéant, votre note du site. Ces informations ne nous sont pas envoyées.

3. Services externes

Pour afficher certains contenus, votre navigateur se connecte directement à d’autres services, qui peuvent recevoir votre adresse IP selon leurs propres politiques :

  • Open-Meteo pour la météo et l’état de la mer.
  • Aladhan pour les horaires de prière.
  • OpenStreetMap et Google Maps pour les cartes.
  • YouTube (sans cookies) uniquement si vous lancez une vidéo.
  • Google Fonts pour les polices et Blogger pour héberger certaines photos.

4. Statistiques et publicité

Nous pouvons utiliser Google Analytics pour mesurer les visites et le site peut afficher des publicités de partenaires ; ces services peuvent alors utiliser des cookies selon leurs politiques. Nous ne vendons aucune donnée.

5. Messages

Si vous nous écrivez sur WhatsApp ou Facebook, votre message sert uniquement à vous répondre.

6. Contact

Pour toute question sur la confidentialité, utilisez la page Contact.
